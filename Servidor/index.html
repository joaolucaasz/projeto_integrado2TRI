Informações do sistema

A leitura é realizada pelo STM32 através do ADC.

O valor é enviado pela USB CDC para o programa em C#.

O programa em C# envia a medição para a API.

O servidor realiza a classificação da satisfação.

O painel consulta a API automaticamente a cada 3 segundos.
